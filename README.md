# 미팅노트 — 고객 미팅 워크스페이스

클로바노트에서 내려받은 녹음과 TXT를 한 미팅으로 등록하고, 발언 근거를 보면서 회의록과 제안서 초안을 관리하는 웹 플랫폼의 첫 실행 버전입니다.

## 지금 실행되는 기능

- 고객사 등록 및 브라우저 저장
- 녹음 파일명 + 클로바노트 TXT 동시 등록
- 시간·화자 표기가 있는 TXT 파싱과 원문 근거 표시
- 연결 전 규칙 기반 회의록 초안, 수정 및 확정
- 참고 TXT·MD 등록과 GPT 전송 허용 정책
- 근거 기반 제안서 템플릿 생성, 수정, 승인, Markdown 다운로드
- Supabase Postgres/RLS/비공개 Storage 마이그레이션
- 인증된 OpenAI 회의록 분석 API 경계

체험 모드 데이터는 현재 브라우저의 `localStorage`에만 저장됩니다. 선택한 녹음 바이트는 저장하지 않아 새로고침 후 재생할 수 없으며 파일명만 유지됩니다. 화면에 표시되는 초기 데이터는 샘플이고, 연결 전 회의록은 규칙 기반 발췌입니다.

## 로컬 실행

```powershell
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:3000`을 엽니다.

검증 명령:

```powershell
npm test
npm run typecheck
npm run build
```

## 클라우드 연결 순서

1. `docs/SUPABASE_SETUP.md`에 따라 개발 Supabase 프로젝트를 준비합니다.
2. `.env.example`을 참고해 `.env.local`을 만듭니다. 실제 키를 Git이나 채팅에 올리지 않습니다.
3. Supabase 마이그레이션과 접근 격리 시험을 개발 프로젝트에서 실행합니다.
4. OpenAI API 결제·프로젝트·키를 준비하고 가상 데이터로 연결을 확인합니다.
5. Vercel 프로젝트에 서버/공개 환경 변수를 구분해 등록합니다.
6. 실제 배포 전에 직접 Storage 업로드와 클라우드 인증 UI를 구현·검증합니다.

## 보안 기준

- OpenAI·Supabase 서버 키는 브라우저 번들에 포함하지 않습니다.
- TXT 경로에서는 녹음을 OpenAI로 보내지 않습니다.
- 생성 결과의 모든 사실 주장은 실제 전사 구간 ID를 참조해야 합니다.
- 클라우드 테이블과 Storage는 조직 멤버십 RLS를 사용합니다.
- 현재 클라우드 계정이 연결되지 않았으므로 운영 서비스로 배포된 상태가 아닙니다.
